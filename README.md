# Smart Recruiters AI — النسخة الداخلية

واجهة داخلية مبنية على Streamlit لتحليل السير الذاتية باستخدام نماذج معالجة اللغة الطبيعية.  
توفر أدوات دقيقة وسريعة تساعد فرق التوظيف على تقييم المرشحين خلال ثوانٍ.

---

## المميزات
- تحليل فوري لمحتوى السيرة الذاتية
- استخراج المهارات والخبرات تلقائيًا
- تقييم المرشح وفق معايير قابلة للتعديل
- توليد تقرير احترافي قابل للتحميل
- واجهة عربية واضحة وسريعة

---

## طريقة العمل
1. رفع السيرة الذاتية  
2. تحليل النص باستخدام نماذج لغوية متقدمة  
3. استخراج المهارات والخبرات  
4. حساب درجة الملاءمة  
5. عرض تقرير شامل للمرشح

---

## التقنية المستخدمة
- Python  
- Streamlit  
- Groq API  
- بنية خفيفة وسريعة مناسبة للأنظمة الداخلية
